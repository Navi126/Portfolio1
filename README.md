# Naveen K - DevOps Portfolio

A responsive one-page DevOps portfolio inspired by modern cloud/DevOps portfolio sites.

## Customize

Open `index.html` and replace:
- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN_USERNAME`
- `YOUR_EMAIL@example.com`
- Project descriptions and links
- Experience details

Add your resume as `resume.pdf` in the project root.

## Run locally

Just open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a GitHub repository, e.g. `devops-portfolio`.
2. Upload all files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. Your portfolio will be published on GitHub Pages.
